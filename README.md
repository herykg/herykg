## 💡 How I Work
 
- **Automate first.** If I do it twice, I look for a script, pipeline, or playbook.
- **Make it reproducible.** Environments should be rebuildable from code, not from memory.
- **Measure before guessing.** Good monitoring shortens every troubleshooting session.
- **Leave it better.** Clear documentation and simple processes outlast the original implementation.
